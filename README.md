# Ceres Web App — GitHub Pages Ready

Мобильный интерактивный прототип покупателя Ceres.

## Публикация
1. Загрузите содержимое этой папки в корень репозитория GitHub.
2. Settings → Pages → Deploy from a branch.
3. Branch: main, folder: /(root).
4. Save.

## Основной demo-flow
7 400 / 10 000 → участие +1 000 → 8 400 → демо-добор до 10 000 → цена 25 ₽ → 21 ₽ → финальные условия → Net Saving.

Все товарные позиции и значения интерфейса, кроме логики сценария, помечены как демонстрационные. Экономия не гарантируется.
